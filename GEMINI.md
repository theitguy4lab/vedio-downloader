
# VideoDownloader - Project Instructions

## Role
Act as an autonomous senior full-stack engineer.

Build this application from the PRD, not from assumptions.

## Stack
- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose

## Architecture
- Separate frontend and backend.
- Use modular architecture.
- Keep controllers, routes, services and models separate.
- Use environment variables for secrets.
- Implement centralized error handling.

## Engineering standards
- Write clean, maintainable code.
- Validate all user inputs.
- Implement authentication securely.
- Handle errors and loading states.
- Avoid duplicated logic.
- Write meaningful tests.
- Document API endpoints.

## Autonomous workflow
1. Read the PRD.
2. Analyze requirements.
3. Create implementation plans.
4. Implement one feature at a time.
5. Run tests after every feature.
6. Fix discovered errors.
7. Update documentation.
8. Commit completed milestones.

## Safety
- Never expose secrets.
- Never commit environment files.
- Never bypass DRM or access restrictions.
- Do not execute destructive commands without approval.
- Do not deploy without approval.
- Do not claim tests passed unless they actually passed.

## Completion criteria
The application must have working frontend,
backend, database integration, authentication,
video download management and automated tests.
